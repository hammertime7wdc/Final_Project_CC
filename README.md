# LK Deliveries - Cloud Deployment Final Project

## Project Overview

LK Deliveries is our CSEC 3 Cloud Computing final project. It is a Python Flet food delivery application that we deployed on Railway. The app supports customer, owner, and admin workflows, and it uses SQLite for local data storage.

## Project Summary

- **Application:** LK Deliveries, a food delivery app
  - Built with Python 3.11 and the Flet web framework
  - Customer, Restaurant Owner, and Admin roles
  - Browse menu, place orders, track delivery, and manage inventory
- **Database:** SQLite local file storage
- **External Services:** Google OAuth for login, Cloudinary for menu images, and SMTP for email notifications
- **Platform:** Railway cloud hosting
- **Deployment:** GitHub connected to Railway for automatic redeploys
